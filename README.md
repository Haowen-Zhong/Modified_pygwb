# Modified_pygwb

This repo contains a modified version of the `pygwb` package, used to produce the
results shown in [arXiv:2606.23816](https://arxiv.org/abs/2606.23816).

## Generating frames

Noise-only and SGWB-only GW frames can be generated by running
`Simulation_scripts/generate_pure_noise_frames.py` and
`Simulation_scripts/generate_SGWB_frames.py`, respectively.

## Reproducing the figures

`Plotting_scripts.ipynb` is the Jupyter notebook that reproduces the plots shown in
the paper. Fig. 15 will differ when a different random seed is used; the point of
that figure is to show that the new expression for the bias factor is more
consistent with the data. It also requires `bias_data_paper.npz` (~1 GB), which is
too large to include in `Data/`.

## Contents of `Modified_pygwb/`

The `Modified_pygwb/` folder contains the modified files of the `pygwb` package.
The key changes are in `postprocessing.py` and `util.py`. `postprocessing.py` adds
several new functions that output optimal narrowband and broadband estimators and variance.

Covariance matrices are not computed explicitly anywhere in the code, but the code
snippet provided in `Plotting_scripts.ipynb` can be used to compute them.


## Note

Aside from the bias factor, which does need to be corrected, the modified version of
`pygwb` is not required to run a stochastic analysis: we show in the paper that the orignal
version of `pygwb` can produce correct broadband estimator and variance, and the broadband estimator
is the sufficient statistics  for the problem, so it can be used directly for downstream analysis.
